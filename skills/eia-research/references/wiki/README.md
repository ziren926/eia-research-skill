这是一份检索入口与链接台账，不是法规现行有效性结论，也不是已下载的报告库。入口见 `catalog.json`，逐份文件的原文页和附件链接见 `documents.json`。首版核对日期：2026-11-23。网站可访问只说明当时能打开；引用前仍须核对发文机关、文号、发布日期、实施日期、修改/废止状态、适用地区和附件正文。

## 查找与入库

1. 先确定项目所在地、审批层级、行业/产品与工艺、污染物、报告书/报告表、检索时间范围。政策先找国家原文，再找省、市、区县细则；报告先找同审批类型、同工艺规模的原始公示。
2. 对每个命中打开正文和附件，区分受理公示、征求意见稿、正式发布、拟审批、审批决定、报告公示稿。优先记录机关网站的固定原文页；PDF、OFD、RAR 等附件另记完整 URL。
3. 将一份文件作为 `documents.json` 的一个 `records` 条目：标题、来源 ID、模块、文种、地区、行业、原文页、附件、公布/实施日期、核对日期、正文核对状态和限制说明。相同文件跨模块只登记一次，用 `module_ids` 关联；修订版单独登记并说明替代关系。
4. 当前仅收录链接，不镜像或批量抓取附件。`link_checked` 只代表页面或附件当时可访问；`full_text_reviewed: false` 不能写成“已读全本”。网址失效、入口改版或效力待定时保留记录并标记待复核，不用猜测性链接顶替。

首批登记含分类名录新旧版本、危废名录、红线监管、VOCs 征求意见稿、技术标准 PDF、环评批复和一个部级公示报告压缩包。压缩包只核对了下载链接，尚未解包核对报告全本。地方同类报告的具体附件需按项目地区和行业继续收集。
